# DynamicWallpaperSwitcher v0.1.0

Initial public source release and **Intel macOS App** build.

## Included

- Tahoe ↔ Golden Gate switching using video assets already available on the user's Mac.
- Conversion of personal SDR videos into Aerial-compatible HEVC dynamic wallpapers.
- Dedicated Custom wallpaper category, media compatibility validation, and user-side backup and recovery safeguards.

## Tested environment

macOS 26.7 on one Intel Mac. The formal GUI import, lock-screen playback, and unlock were verified with a 3840 × 2160, 30 fps, HEVC Main10 / BT.709 personal source. The repository and release do not contain that video or any Apple wallpaper video.

## Download

`DynamicWallpaperSwitcher-v0.1.0-macos-intel.zip` contains an **x86_64-only** App and its x86_64 media helper. It is ad-hoc signed and **not notarized**. It does not include FFmpeg, ffprobe, or x265; install compatible command-line versions separately. The source project can also be built with Xcode.

ZIP SHA-256: `ac2b5fc3428dde0f81383aedb573ccb5c4633fdefdc11d0339a82b7357b79240`.

Apple Silicon has not been tested. An Intel app may run there through Rosetta, but this release does not claim that its wallpaper integration works on Apple Silicon. A native or universal build would require both the App and bundled helper to include arm64 code and must be tested on Apple Silicon before being labeled supported.

## Limitations

HDR, BT.2020, and full-range inputs are not supported. Other macOS versions, more source formats, and substantially longer videos remain unverified. Apple's Aerial provider internals can change across macOS releases.

## Safety

The App works only in the current user's wallpaper data. It does not write to `/System`, require administrator privileges, or change SIP/SSV. This is an unofficial community project and is not affiliated with Apple.
