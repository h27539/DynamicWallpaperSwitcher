# Changelog

## v0.1.0 — initial public release

- Tahoe ↔ Golden Gate user-side wallpaper switching.
- Custom Aerial video conversion, compatibility validation, dedicated Custom category, and native playback on the tested macOS 26.7 Intel host.
- Manifest, localization, and cache backup and recovery safeguards.
- Public release hygiene: local media and logs excluded, release-only UI excludes experimental controls, documentation and contribution files added.

The initial binary release is Intel-only; Apple Silicon has not been verified.
